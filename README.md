`app:layout_constraintHorizontal_chainStyle="spread"` - elementy są równomiernie rozłożone z wolnym miejscem na początku, końcu i między nimi

`app:layout_constraintHorizontal_chainStyle="spread_inside"` - elementy są równomiernie rozłożone, ale pierwszy i ostatni przyklejają się do krawędzi

`app:layout_constraintHorizontal_chainStyle="packed"` - elementy są ściśnięte razem i cała grupa jest wyśrodkowana
#
